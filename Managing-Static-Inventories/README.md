## 🔑 Key Concepts

| 📌 Term | 📖 Meaning |
|---|---|
| **Static Inventory** | A fixed file that defines the hosts and groups Ansible manages |
| **YAML Inventory** | A static inventory written in YAML, supporting nested groups and variables |
| **Host Grouping** | Organizing hosts into logical groups such as web servers, databases, load balancers, and monitoring |
| **Hierarchical Structure** | Groups nested within groups to model multi-tier applications |
| **Group Variables** | Variables applied to every host in a group |
| **Host Variables** | Variables applied to a single host |
| **Inheritance Patterns** | How hosts receive variables from the groups they belong to |
| **Version Control Integration** | Keeping inventory files in Git for change tracking and audit trails |
