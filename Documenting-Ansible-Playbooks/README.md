## 📋 Lab Summary

In this lab, you built a small but complete **Ansible project** demonstrating documentation best practices at every level of the automation stack. You verified each artifact by actually running it, rather than just writing comments, which reinforced the principle that **good documentation must stay synchronized with working code**.

| # | Artifact | Details |
|---|----------|---------|
| 1 | 🗂️ **Inventory & Group Variables** | An annotated inventory and group variables file |
| 2 | 📜 **Playbook** | A fully commented playbook with tagged tasks and pre/post-task reporting |

## 📚 Key Concepts

| Concept | Description |
|---------|-------------|
| **Annotated Inventory** | Inventory and group variables file with explanatory comments |
| **Commented Playbook** | Playbook with documented tasks, tags, and pre/post-task reporting |
| **Role Defaults** | Documented default variables for a role |
| **Role README** | Describes a role's variables, dependencies, and test procedure |
| **Docs/Code Synchronization** | Good documentation must stay synchronized with working code |
